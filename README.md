# 🔐 ZAIN-VAULT-LOCKER v2.0
A secure, CLI-based AES-256 encrypted vault built for **Termux** and **Linux** environments. Manage your passwords, confidential text notes, and secure files with high-grade encryption.

---

### 🚀 Features
* **AES-256 Encryption:** Secured via PBKDF2HMAC and Fernet cryptography.
* **Multi-Purpose Locker:** Store website passwords, secret notes, and lock/restore sensitive images or files.
* **Master Password Rotation:** Easily change your master security key anytime.
* **Global CLI Command:** Run the tool instantly from anywhere in your terminal using `zain-vault`.

---
